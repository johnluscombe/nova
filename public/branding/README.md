# Nova logo

An angular N, a radar scan arc, and a bright return point connect Nova's name
with its radar imagery workflow. Cyan and white sit on a navy app tile.

The master is `nova-logo.png`, generated with the built-in image generation tool.
PNG, ICO, and ICNS derivatives are generated with
`node scripts/generate-icons.ts` on macOS. The header uses a bundled 96px copy
at `src/assets/nova-logo.png`.

## Generation prompt

Use case: logo-brand
Asset type: Nova desktop application icon for a radar data imagery viewer supporting SICD imagery.
Primary request: Design one polished distinctive minimalist logo, an abstract capital N composed of two crisp broad angular signal ribbons, intersected by a single subtle orbital radar scan arc with a small bright return point. Suggest precision imaging and the name Nova. Flat geometric design with very simple bold silhouette readable at 24 pixels.
Color palette: icy cyan and white signal mark on a deep navy blue rounded-square app tile, matching a professional blue desktop ribbon interface.
Composition: one centered icon only, square 1024x1024 canvas, tile occupies 88 percent of canvas with transparent space outside the rounded corners. Generous internal padding. The N is the clear dominant feature; radar arc secondary.
Constraints: genuinely transparent outside tile; no lettering or wordmark, no mockup, no border, no tiny grids, no gradients, no shadows, no photographic elements. Professional scientific imaging software identity.
